## How I approach development

- **Function first** — resources should work reliably before anything else.
- **Clean presentation** — interfaces should feel clear, consistent, and easy to use.
- **Compatibility matters** — integrations should respect the framework and resources already running on your server.
- **Straightforward communication** — clear scope, realistic progress updates, and practical solutions.
